\# Navalha de Ouro — Landing Page de Barbearia



Landing page responsiva para uma barbearia fictícia, desenvolvida como

projeto de prática em HTML, CSS e JavaScript.



\## Sobre o projeto



O objetivo deste projeto foi praticar a criação de uma landing page completa,

com foco em responsividade, interação com JavaScript e experiência do usuário.



\## Tecnologias



\- HTML5

\- CSS3

\- JavaScript

\- Flexbox

\- CSS Grid

\- Design responsivo



\## Funcionalidades



\- Menu responsivo para dispositivos móveis

\- Seção principal com chamadas para ação

\- Cards de serviços

\- Galeria com filtros

\- Lightbox para visualização das imagens

\- Slider de depoimentos

\- Formulário de contato

\- Integração com WhatsApp

\- Mapa incorporado

\- Botão para voltar ao topo

\- Animações e transições

\- Layout responsivo



\## O que pratiquei neste projeto



\- Estruturação semântica com HTML5

\- Criação de layouts responsivos com CSS

\- Manipulação do DOM com JavaScript

\- Eventos e interações do usuário

\- Criação de componentes visuais reutilizáveis

\- Organização de arquivos em um projeto web



\## Como executar



Baixe ou clone o repositório e abra o arquivo `index.html`

em um navegador.
